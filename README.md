# Inevitable

Brand files for **inevitable**, Sal’s weekly LinkedIn newsletter on Solana in AU/NZ.

Community register. Not Milysec. Mark signed off 1 September 2026.

The I is the display character.

## Style guide

This repository is the guide. Serve the repo root.

- Local: open `index.html`
- GitHub Pages: enable Pages from **/** (root). The guide is `index.html`.

Repo: [github.com/metasal1/inevitable](https://github.com/metasal1/inevitable)

## Locked

**Colour.** Ground `#000000`, ink `#FFFFFF`. Accents (editorial only, never on the mark, one at a time): purple `#800080`, blue `#0000FF`, red `#FF0000`. No Milysec mint or lab purple.

**Type.** Inter 400/500/600. Wordmark: lowercase `inevitable`, Inter 600, slight negative tracking. No MoonWalk, Bricolage Grotesque, EconoSans, Monoton, Orbitron, Geist.

**Mark.** Three copies of the official Solana top-bar parallelogram. Stem rotated −90°. Bottom not flipped. Gaps are the field.

See `STYLEGUIDE.md`.
